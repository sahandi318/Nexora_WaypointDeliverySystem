# AI Tool Disclosure

## Nexora Waypoint Delivery System

This document describes how Artificial Intelligence (AI) tools were used during the design and development of the Nexora Waypoint Delivery System for Tech-Triathlon 2026.

---

## AI Tools Used

The team used the following AI-assisted tools during the project:

- **ChatGPT (OpenAI)**

These tools were used as development and design assistants. They were not used to independently build or submit the complete solution without team review.

---

## AI-Assisted Work

### 1. UI/UX Design Assistance

AI tools were used to support:

- brainstorming interface ideas
- improving layout, spacing, alignment and responsiveness
- refining the visual consistency of role-specific interfaces
- suggesting mobile-friendly layouts for Driver and Loader interfaces
- improving professional dashboard layouts
- developing and refining some Figma design concepts
- checking consistency between the Designathon workflow and Hackathon implementation

The team made the final design decisions and reviewed the generated suggestions before implementation.

---

### 2. Software Development Assistance

ChatGPT was used to assist with:

- React component structure and implementation suggestions
- Node.js and Express API development
- Prisma schema and migration troubleshooting
- MySQL integration guidance
- JWT authentication and role-based access control guidance
- Store Manager, Dispatcher, Loader and Driver workflow integration
- Socket.IO real-time communication suggestions
- PWA and offline synchronization implementation guidance
- debugging frontend and backend errors
- reviewing API and database connections
- improving code organization and readability

AI-generated code was reviewed, modified and integrated by the team according to the existing project architecture.

---

### 3. Testing and Debugging Assistance

AI was used to help:

- identify possible causes of frontend and backend errors
- debug Prisma migration and database schema issues
- suggest API and role-integration test cases
- prepare unit, API and end-to-end testing approaches
- verify expected workflow behavior across the four main roles

The team executed the tests, investigated actual runtime results and made the final corrections.

---

### 4. Documentation Assistance

AI tools were used to help draft and improve:

- README content
- architecture descriptions
- data-model explanations
- setup and deployment instructions
- user workflow descriptions
- seeded-account documentation
- testing documentation
- AI disclosure documentation

All documentation was reviewed and adjusted by the team to reflect the actual implemented system.

---

## Work Performed and Validated by the Team

The project team was responsible for the final engineering and design decisions, including:

- selecting the final technology stack
- defining the overall system architecture
- implementing and integrating the frontend and backend
- designing the database relationships
- integrating the four operational roles:
  - Store Manager
  - Dispatcher
  - Loader
  - Driver
- configuring authentication and authorization
- importing and working with the competition data
- testing application workflows
- reviewing and correcting AI-assisted code
- resolving Git and merge conflicts
- configuring deployment
- validating the final deployed application
- preparing the final competition submission

The team did not accept AI-generated outputs without review. Suggestions were evaluated, modified where necessary and tested before being included in the final solution.

---

## Use of Competition Data

The competition datasets were used only for the purposes of the Tech-Triathlon 2026 project.

The team did not intentionally publish or distribute the original competition datasets through AI tools or public repositories.

Where demonstration data was required for application-specific features, it was kept separate from the original competition datasets where appropriate.

---

## Final Responsibility

AI tools were used as supporting tools for development, design, debugging and documentation.

The project team remains responsible for:

- the final submitted source code
- system architecture
- database design
- application behavior
- testing
- deployment
- design decisions
- documentation
- competition compliance

All final outputs were reviewed by the team before submission.
